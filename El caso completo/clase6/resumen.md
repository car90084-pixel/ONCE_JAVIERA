# El Caso Completo

## Objetivo

Integrar todos los conocimientos de las clases anteriores en un proyecto real.

## Fases

### 1. Metodología
Se utiliza Scrum porque permite adaptarse a cambios frecuentes.

### 2. Requisitos

#### Funcionales
- Reservar cancha.
- Cancelar reserva.
- Consultar disponibilidad.
- Recibir notificaciones.

#### No Funcionales
- Máximo 2 reservas activas.
- Disponibilidad 24/7.

### 3. Elicitación
- Entrevistas.
- Encuestas.
- Observación directa.

### 4. Documentación
- Documento SRS.
- Casos de uso.
- Requisitos identificados.

### 5. Diseño
- Wireframes.
- Prototipos.
