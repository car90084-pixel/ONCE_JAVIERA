# Requerimientos de Software - Resumen

## ¿Qué es un requerimiento?

Es una propiedad documentada y verificable que un sistema debe cumplir para resolver una necesidad o alcanzar un objetivo.

### Características de un buen requerimiento

- Necesario
- No ambiguo
- Verificable
- Consistente
- Completo
- Atómico
- Trazable

## Niveles de abstracción

1. Necesidad del usuario
2. Requerimiento del sistema
3. Especificación técnica

## Requerimientos Funcionales (RF)

Describen las acciones que realiza el sistema.

### Ejemplos

- Registrar usuarios
- Calcular promedios
- Mostrar información
- Generar reportes
- Enviar notificaciones

### Categorías

- Autenticación
- Cálculo
- Persistencia
- Comunicación
- Reportes
- Validación

## Requerimientos No Funcionales (RNF)

Describen cómo debe comportarse el sistema.

### Tipos

- Rendimiento
- Seguridad
- Usabilidad
- Confiabilidad
- Escalabilidad
- Mantenibilidad
- Portabilidad
- Cumplimiento legal

## Diferencia entre RF y RNF

| RF | RNF |
|----|-----|
| Qué hace el sistema | Cómo debe ser el sistema |
| Funciones | Calidad y restricciones |
